# QR Code Generator

## 📌 Description

A simple Python application that generates QR codes from user-entered text or URLs and saves them as PNG images.

## 🚀 Features

- Generate QR codes from text or URLs
- Save QR code as PNG
- Simple and beginner-friendly
- Fast execution

## 🛠️ Technologies Used

- Python
- qrcode
- Pillow

## 📂 Project Structure

QR-Code-Generator/
│
├── app.py
├── requirements.txt
├── README.md
├── .gitignore
├── LICENSE
├── output/
└── screenshots/

## ▶️ Installation

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

```bash
python app.py
```

## 📸 Output

The generated QR code is saved inside the `output` folder as `qr.png`.
